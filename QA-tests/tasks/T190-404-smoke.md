# T190-404-smoke: 404 page — renders, CTAs, mobile

| Field | Value |
|---|---|
| Route | `/404.html` |
| Source | `404.html` |
| Flow | Smoke — not-found page renders and its two CTAs lead somewhere valid |
| Requires auth | no |
| Required role | anonymous |
| Destructive | no |
| Estimated steps | 12 |

## Preconditions
- App running at `http://localhost:8080`
- anonymous
- Note: CTA hrefs and the logo `src` are absolute to the GitHub Pages base path `/Pushpak-enterprises-website-and-CRM/`. On the local dev server at the root `http://localhost:8080/`, those paths resolve only if the dev server maps that prefix. Record the result for each environment.

## Test data
- `nonexistentPath = "/qa-does-not-exist-190.html"`
- `expectedTitle = "Page not found — Pushpak Enterprises"`
- `expectedH1 = "This page doesn't exist, or has moved."`

## Steps

### TC-01: Happy path — 404 page renders
1. Navigate to `http://localhost:8080/404.html`.
2. Assert: HTTP 200; `document.title` is `Page not found — Pushpak Enterprises`; `<meta name="robots">` is `noindex`.
3. Assert: the badge `ERROR 404`, the large `404`, and the `<h1>` `This page doesn't exist, or has moved.` are visible, followed by the paragraph starting `The link may be broken.`.
4. Assert: the top bar shows `Pushpak Enterprises`. The logo image either loads or is hidden by its `onerror` (it must never appear as a broken image icon).
5. Navigate to `http://localhost:8080/qa-does-not-exist-190.html`. Assert: the server returns status 404, and if the host serves the custom page, the same H1 is shown.

### TC-02: CTA coverage
| Button | Action taken | Expected result |
|---|---|---|
| `Go to homepage` | click | navigates to `/Pushpak-enterprises-website-and-CRM/`, which renders the Pushpak Enterprises home page (HTTP 200). FAIL and log a bug if it 404s on the local dev server because of the hard-coded base path. |
| `Contact us` | click | navigates to `/Pushpak-enterprises-website-and-CRM/#contact`; the home page loads and the `#contact` element exists |
| Footer `Privacy` / `Terms` / `Cookies` (injected by `pe-trust.js`, if present) | request | each returns 200 |
| `Cookie settings` (if injected) | click | `Cookie settings` dialog opens; Esc closes |

### TC-03: Phone width (375px)
1. Set the viewport to 375 × 812 and reload `/404.html`.
2. Assert: `document.documentElement.scrollWidth <= 375`; the `404` numeral scales down (no clipping); both CTAs are fully visible, at least 48px tall, and wrap without overflow.

## Assertions
- [ ] Title `Page not found — Pushpak Enterprises`, H1 `This page doesn't exist, or has moved.`.
- [ ] An unknown URL returns HTTP 404.
- [ ] `Go to homepage` and `Contact us` resolve (no 404) — record any base-path mismatch.
- [ ] No broken logo image.
- [ ] No page-level horizontal scroll at 375px.
- [ ] No console errors in DevTools at any step.
- [ ] No failed network requests (no 4xx/5xx) except the intentional unknown-URL 404.

All TCs above pass AND no unexpected console/network errors.
