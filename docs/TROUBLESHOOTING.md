# Troubleshooting

| What you see | Likely reason | What to do |
|---|---|---|
| Red bar: "You're offline" | Phone/computer has no internet | Reconnect. Wait for the green "Back online". Check the record before saving again. |
| Red bar: "Something went wrong…" | A page error | Refresh. If it repeats, note the screen and time, send to Admin. |
| "You don't have permission" | Wrong role, or account switched off | Sign out and in. If still blocked, ask Admin to check the account and your role. |
| Sent back to the login page | Session ended, or account switched off | Sign in again; if the login page gives a reason, follow it. |
| Cannot assign a technician | On leave / not working that day / not authorized for the brand / suspended | Pick another, or fix the technician's profile. |
| Appointment refused | Outside working hours, break, closure, daily job limit, or clash | Choose another slot (the page suggests free ones). |
| Spare request or consume refused: "Only N in …" | Not enough stock | Check the count; request or transfer more. |
| Document will not open | Browser blocked the pop-up | Allow pop-ups for the site, or use Download. |
| Print is cut off / wrong size | Wrong paper size chosen | Pick the size matching the paper (A4/A5/A6/Thermal); in the print window set margins to Default. |
| WhatsApp button missing | No valid 10-digit mobile number on the record | Add the customer's mobile number. |
| Numbers look old | Cached page | Hard refresh (Ctrl+F5 / pull to refresh). |
| Something changed and nobody knows who | — | Admin → Audit log. |

Server problems (functions failing, many users blocked): see MONITORING.md and DEPLOY-ROLLBACK.md.
